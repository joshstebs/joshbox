Connect once. Create from your studio.

The dashboard is built. Real generation needs your running GPU, an authenticated video proxy, and a verified workflow. No GPU rental or model installation is started by this site.

Keep your working setup

  1. Preserve the existing Vast.ai ComfyUI installation and MiniMax H3 models. The wrapper is added beside them.
  2. Install the supplied Python wrapper in its own environment. Configure its private VIDEO_PROXY_TOKEN and the API export of your working workflow.
  3. Run start_vast.sh. It checks the GPU, starts ComfyUI on localhost:8188, and exposes the authenticated wrapper on port 8080. It refuses occupied ports to avoid duplicate processes.
  4. Expose the wrapper through the protected Vast proxy with trusted HTTPS. Configure the Site's protected VIDEO_PROXY_URL and matching VIDEO_PROXY_TOKEN server values. Keep tokens out of chat, browser fields, source, and URLs.
  5. Check the connection from JoshBox. Test a short clip, watch the real step/node monitor, confirm Saved, and download it before stopping the GPU.

Quick picks and Boost

MiniMax, Wan, LTX, and Hunyuan buttons load draft settings. Setup needed means the corresponding API workflow is unavailable. Boost uses the selected model's configured Fast workflow; it does not download an accelerator or rent a different GPU.

Extend Video

A saved video supplies its final frame as the next starting image. Write what happens next, then generate a separate clip. Clips are not automatically joined and previous audio is not carried forward.

Private gallery

Finished files are copied into private storage while JoshBox is open or after you return. Keep the GPU running until the app says Saved. Hosted gallery downloads then remain independent of the GPU.

The repository README and supplied startup bundle contain the complete administrator setup. Daily creation stays in this dashboard without a node graph.
