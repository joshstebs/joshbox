A fresh GPU. Your familiar studio.

Wan 2.2 is the default engine. MiniMax H3 remains the Audio alternate. The app does not rent GPUs; model setup starts only when you run the supplied setup on your manually rented instance.

Permanent source, disposable compute

GitHub holds the app, workflow JSON, pinned model manifest, and setup scripts. Public base weights stay in their official Hugging Face repositories. Your private GodofThrones/joshbox-assets repository is reserved for custom/private assets.

Fresh-instance setup

  1. Use a PyTorch/CUDA Vast instance. Place the reviewed JoshBox checkout at /workspace/joshbox. Keep an existing ComfyUI installation and models; the installer will not pull/reset them.
  2. Set the protected VIDEO_PROXY_TOKEN environment secret, then run bash /workspace/joshbox/scripts/setup-vast.sh. The script prepares dependencies, verifies/downloads the selected models, and launches the wrapper and local ComfyUI.
  3. Default profiles are wan22-fast,wan22-quality: about 38 GB. Add minimax-h3 or minimax-h3-fast through JOSHBOX_BOOTSTRAP_PROFILES when you want the additional audio family. A fresh machine still needs the cloud-to-datacenter transfer.
  4. For compatible Vast SSH instances, use the supplied scripts/onstart.sh as /root/onstart.sh. Review/preserve existing startup hooks. Custom-command instances can use it as their startup command.
  5. Expose the authenticated wrapper on port 8080 through your trusted HTTPS proxy. Set the Site's protected VIDEO_PROXY_URL and matching token. Your dashboard reports actual Offline, Starting, Downloading Models, Ready, and Generating states.

Private Hugging Face assets

Public models need no HF token. Optional private assets require a repo-scoped read token on the GPU and a pinned private manifest revision. Keep an upload token separate. Tokens stay out of chat, GitHub, workflow files, URLs, and browser JavaScript.

Ready means ready to submit

The wrapper checks ComfyUI health, required core nodes, and model-file presence before enabling a workflow. Rendering, memory use, and speed still need a real GPU test. Unsupported presets remain unavailable.

Save before shutting down

Finished video must reach the private gallery before the app says Saved. Extend Video uses its last frame to create a separate clip. Keep JoshBox open or reopen it to archive results. Manage rental shutdown/destruction in Vast.ai; stopping these programs alone does not manage your rental.
